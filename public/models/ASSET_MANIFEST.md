# Astraified harbor assets

`harbor-telescope.glb` and `harbor-lighthouse.glb` are original procedural artwork
authored for Astraified. They are generated by
`scripts/blender/build_harbor_props.py` using Blender 4.5.0.
No third-party models, textures, or image assets are included.

The browser imports the local glTF assets into the harbor's observatory lawn.
Procedural versions remain visible if the assets cannot be loaded. The lighthouse
lantern is a runtime mesh so its glow is controlled by the actual game state.
Blender is only needed to regenerate the asset; players do not need it.

Development runtime source: https://download.blender.org/release/Blender4.5/blender-4.5.0-macos-arm64.dmg

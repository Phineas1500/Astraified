# Source-generated adventure QA — September 10, 2026

## Implemented path

The cover's **Create an adventure** opens the new episode studio. It accepts pasted text, a public URL, or a supported file, then runs source extraction, a quoted learning plan, story generation, and deterministic package certification. Completed stages persist in private `.astraified/jobs/` files. The browser keeps the active job ID, six recent packages, and separate progress/drafts for each episode edition.

This first version requires material covering all three Transformer families: position, scaled dot-product attention, and causal masking. It creates new dialogue, clues, inventory dependencies, discoveries and scene arrangements using the existing harbor artwork and three reviewed numerical instruments. It does not generate new mechanics, 3D worlds, or artwork.

## Practical limits

One successful generated case establishes an integration example, not a measured generation success rate. Exact quotations and executable state checks do not prove every narrative statement is supported, that clues are fair, or that learners retain the concepts. Human review and playtesting with high-school/college learners remain necessary. The instruments use illustrative vectors, not a trained language model.
